## Лабораторная работа №2. Использование PHP

Папка: [`lab2`](./lab2/)

### Цель

Получить навык разработки сайтов с использованием языка программирования PHP.

### Основные требования

- разработать сайт по теме варианта 3 — новостной сайт;
- стилизовать сайт с помощью CSS; разрешено использовать Bootstrap;
- вывести таблицу с информацией, которая хранится на сервере в отдельном текстовом, XML- или JSON-файле;
- реализовать добавление новых данных и их сохранение в файл.

### Что реализовано

За основу взят статический новостной сайт из первой лабораторной работы. Он дополнен динамическими страницами и работой с файлом:

- [`index.php`](./lab2/index.php) — главная страница, которая читает новости из JSON и выводит их в таблице «Новости пользователей»;
- [`adding_news.php`](./lab2/adding_news.php) — страница с формой добавления новости и PHP-обработчиком;
- [`news.json`](./lab2/news.json) — файл, в котором хранятся названия, категории и даты новостей;
- [`economics.html`](./lab2/economics.html) и [`culture.html`](./lab2/culture.html) — сохранённые тематические страницы первой работы;
- [`style.css`](./lab2/style.css) — общий файл оформления;
- `c.webp` — баннер страницы добавления новости.

В навигации доступны четыре раздела: главная страница, экономика, культура и добавление новости. Таблица пользовательских новостей расположена в конце главной страницы, поскольку количество записей может увеличиваться.

### Как работает главная страница

В начале `index.php` функция `file_get_contents()` читает всё содержимое `news.json` в строку:

```php
$str = file_get_contents("news.json")
    or die("Не удалось прочитать файл с новостями");
```

Если файл прочитать невозможно, `die()` выводит сообщение и прекращает выполнение PHP-скрипта. Затем функция `json_decode()` преобразует JSON-строку в PHP-массив:

```php
$news = json_decode($str, true);
```

Значение `true` означает, что элементы JSON преобразуются в ассоциативные PHP-массивы. После этого цикл `foreach` перебирает все новости и формирует строки HTML-таблицы:

```php
<?php foreach ($news as $item): ?>
    <tr>
        <td><?php echo $item["title"]; ?></td>
        <td><?php echo $item["category"]; ?></td>
        <td><?php echo $item["date"]; ?></td>
    </tr>
<?php endforeach; ?>
```

### Как работает добавление новости

Форма на странице `adding_news.php` отправляет данные методом `POST` на эту же страницу:

```html
<form method="post" action="adding_news.php">
```

У полей заданы имена `title`, `category` и `date`. По этим именам PHP получает значения из массива `$_POST`:

```php
$title = $_POST["title"];
$category = $_POST["category"];
$date = $_POST["date"];
```

Условие с `$_SERVER["REQUEST_METHOD"]` не позволяет выполнять код добавления при обычном открытии страницы:

```php
if ($_SERVER["REQUEST_METHOD"] == "POST")
```

Новая запись создаётся как ассоциативный массив и добавляется в конец массива новостей:

```php
$newItem = [
    "title" => $title,
    "category" => $category,
    "date" => $date
];

$news[] = $newItem;
```

Файл открывается в режиме `w`, то есть его прежнее содержимое заменяется новым. Старые новости не теряются: перед записью они были прочитаны в `$news`, а новая запись была добавлена к этому массиву.

```php
$fd = fopen("news.json", "w")
    or die("Не удалось открыть файл для записи");
```

Массив преобразуется обратно в JSON и записывается в файл:

```php
fwrite(
    $fd,
    json_encode($news, JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT)
);
fclose($fd);
```

- `json_encode()` преобразует PHP-массив в JSON;
- `JSON_UNESCAPED_UNICODE` оставляет русские буквы читаемыми;
- `JSON_PRETTY_PRINT` добавляет отступы и переносы строк;
- `fwrite()` записывает строку в открытый файл;
- `fclose()` закрывает файл после записи.

### Поля формы

- `input type="text"` — поле ввода названия новости;
- `select` и вложенные `option` — выпадающий список категорий;
- `input type="date"` — выбор даты;
- `required` — браузер не отправляет форму, пока обязательное поле не заполнено;
- `input type="submit"` — кнопка отправки формы.

Проверка значений в PHP дополнительно не позволяет записать пустую новость, даже если клиентскую проверку `required` обойдут.

### Полный порядок выполнения запроса

1. Пользователь открывает `adding_news.php` через веб-сервер.
2. PHP читает существующие новости из `news.json`.
3. Пользователь заполняет форму и нажимает кнопку добавления.
4. Браузер отправляет поля серверу методом `POST`.
5. PHP получает значения из `$_POST` и создаёт новую запись.
6. Запись добавляется в массив существующих новостей.
7. Весь обновлённый массив сохраняется в `news.json`.
8. При открытии или обновлении `index.php` данные заново читаются из файла и появляются в таблице.

### Что использовано сверх примеров методички

Основной код опирается на темы из методички: PHP-вставки, переменные, массивы, `foreach`, формы, `$_POST`, `$_SERVER`, `fopen()`, `fwrite()`, `fclose()`, `file_get_contents()` и `die()`.

В методичке разрешён формат JSON, но подробно не показаны следующие используемые средства:

- `json_decode()` — преобразование JSON в PHP-массив;
- `json_encode()` — обратное преобразование массива в JSON;
- `JSON_UNESCAPED_UNICODE` и `JSON_PRETTY_PRINT` — параметры оформления JSON;
- `required` — встроенная браузерная проверка заполнения формы.

Все эти средства входят в стандартные возможности PHP или HTML, сторонние библиотеки и фреймворки в работе не применялись.

### Важные нюансы к защите

- PHP выполняется на сервере, а браузер получает уже сформированный HTML.
- Страницу PHP нужно открывать через `http://localhost/...`, а не как локальный файл двойным щелчком.
- Все посетители сайта работают с одним файлом `news.json`. Авторизации нет, поэтому при публикации сайта добавить новость сможет любой посетитель страницы формы.
- Сервер должен иметь право записи в `news.json`, иначе `fopen()` не сможет открыть его в режиме `w`.
- Режим `w` очищает файл перед записью, но код сначала сохраняет старые данные в массиве и записывает обратно уже полный обновлённый массив.
- После отправки формы повторное обновление страницы может повторно отправить данные и создать дубликат. Для простой лабораторной перенаправление после POST не реализовано.
- Данные выводятся напрямую через `echo`. Для общедоступного сайта пользовательский текст следовало бы обрабатывать функцией `htmlspecialchars()`, но в этой локальной учебной работе она не используется для упрощения кода.
- Если вручную нарушить структуру `news.json`, `json_decode()` не сможет получить корректный массив. Поэтому в JSON важны кавычки, запятые и квадратные скобки.
- `die()` в этой работе используется как простая обработка ошибки: выводит сообщение и прекращает выполнение скрипта. Это не полноценная конструкция исключений `try/catch`.
- Таблица на главной формируется динамически: её строки отсутствуют в HTML в готовом виде и создаются циклом `foreach` при каждом запросе страницы.
