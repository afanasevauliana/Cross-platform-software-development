# Лабораторная работа № 3 — браузерная игра «Змейка»

## Общая информация

Лабораторная работа выполнена по дисциплине «Кроссплатформенная разработка программного обеспечения».

- Тема: JavaScript.
- Вариант: 3.
- Задание: разработать браузерную игру «Змейка».
- Методические указания: `ЛП_КРПО-32-44.pdf`.

Цель работы — получить практические навыки разработки на JavaScript, подключения сценария к HTML-странице, работы с DOM, событиями и Canvas.

## Результат работы

Разработана игра, в которой пользователь управляет змейкой с помощью клавиш со стрелками. Змейка перемещается по клеточному полю, съедает еду и увеличивается в длину. Игра завершается при столкновении со стеной или собственным телом.

В игре реализованы:

- начальный экран с кнопкой «Начать игру»;
- движение змейки с постоянным интервалом;
- управление клавишами со стрелками;
- запрет мгновенного разворота в противоположную сторону;
- запрет изменения направления больше одного раза за игровой шаг;
- случайное размещение еды;
- проверка, чтобы еда не появилась внутри змейки;
- увеличение длины змейки после поедания еды;
- подсчёт текущих очков;
- сохранение рекорда в `localStorage`;
- столкновение со стеной;
- столкновение с собственным телом;
- сообщение о причине окончания игры;
- повторный запуск без перезагрузки страницы.

Атрибут `defer` позволяет сначала загрузить HTML, а затем выполнить сценарий. Благодаря этому JavaScript может найти все необходимые элементы страницы.

## Этапы разработки

Проект создавался последовательно небольшими блоками. После каждого этапа проверялось, как работает добавленная часть.

### 1. Создание HTML-страницы и Canvas

В HTML был создан элемент Canvas размером 600 × 600 пикселей:

```html
<canvas id="game-canvas" width="600" height="600"></canvas>
```

Canvas является областью, внутри которой JavaScript рисует игровое поле, змейку и еду.

В JavaScript Canvas был найден через DOM, после чего был получен двумерный контекст рисования:

```js
const canvas = document.getElementById("game-canvas");
const context = canvas.getContext("2d");
```

### 2. Оформление страницы

В `style.css` страница была оформлена с помощью Flexbox. Заголовок, счёт и игровое поле выровнены по центру. Для страницы выбран тёмно-синий фон, а Canvas получил границу и светлый фон.

### 3. Деление поля на клетки

Размер одной игровой клетки хранится в константе:

```js
const cellSize = 20;
```

При размере Canvas 600 × 600 пикселей игровое поле содержит 30 × 30 клеток:

```text
600 / 20 = 30
```

Координаты игровых объектов хранятся в клетках, а перед рисованием переводятся в пиксели умножением на `cellSize`.

### 4. Представление и рисование змейки

Змейка представлена массивом объектов. Каждый объект содержит координаты одной части тела:

```js
const snake = [
  { x: 10, y: 10 },
  { x: 9, y: 10 },
  { x: 8, y: 10 }
];
```

Первый элемент массива `snake[0]` является головой.

Для перебора частей змейки используется обычный цикл `for`. Он был выбран вместо `forEach`, поскольку его работу проще последовательно проследить и объяснить:

```js
for (let i = 0; i < snake.length; i++) {
  const part = snake[i];
  context.fillRect(
    part.x * cellSize,
    part.y * cellSize,
    cellSize,
    cellSize
  );
}
```

### 5. Очистка Canvas

Перед каждым новым кадром старое изображение удаляется:

```js
function clearCanvas() {
  context.clearRect(0, 0, canvas.width, canvas.height);
}
```

Без очистки старые положения змейки оставались бы на игровом поле.

### 6. Перемещение змейки

Для движения создаётся новая голова со смещёнными координатами:

```js
const newHead = {
  x: head.x + directionX,
  y: head.y + directionY
};
```

Новая голова добавляется в начало массива методом `unshift()`. При обычном движении последний элемент удаляется методом `pop()`. Поэтому длина змейки остаётся прежней, но её положение меняется.

### 7. Игровой цикл

Один шаг игры выполняет следующие действия:

1. Очищает Canvas.
2. Перемещает змейку.
3. Проверяет столкновения.
4. Рисует новое положение змейки и еды.
5. Планирует следующий шаг.

Для повторения используется `setTimeout`, поскольку эта функция рассматривается в методических указаниях:

```js
setTimeout(gameLoop, 300);
```

Интервал между шагами составляет 300 миллисекунд. Каждый выполненный `gameLoop()` назначает следующий вызов.

### 8. Управление с клавиатуры

Нажатия клавиш обрабатываются через событие `keydown`:

```js
document.addEventListener("keydown", changeDirection);
```

Направление хранится двумя числами:

```text
вправо: directionX =  1, directionY =  0
влево:  directionX = -1, directionY =  0
вниз:   directionX =  0, directionY =  1
вверх:  directionX =  0, directionY = -1
```

Условия запрещают сразу выбрать противоположное направление. Дополнительный флаг `directionChanged` не позволяет обработать два поворота между соседними перемещениями. Это предотвращает ситуацию, когда быстрое нажатие двух стрелок разворачивает голову в тело змейки.

### 9. Проверка столкновений

После перемещения проверяются координаты головы.

Столкновение со стеной происходит, если голова вышла за любую границу Canvas:

```js
head.x < 0
head.y < 0
head.x * cellSize >= canvas.width
head.y * cellSize >= canvas.height
```

Для проверки столкновения с телом голова сравнивается с остальными элементами массива. Цикл начинается с индекса `1`, поскольку индекс `0` принадлежит самой голове.

Если произошло столкновение, новый вызов `setTimeout()` не назначается и игровой цикл останавливается.

### 10. Создание еды

Еда хранится как объект с координатами:

```js
const food = { x: 20, y: 15 };
```

Она рисуется красным прямоугольником. После поедания новые координаты создаются с помощью `Math.random()` и округляются методом `Math.floor()`.

Дополнительный цикл проверяет все части змейки. Если случайная клетка занята, координаты генерируются повторно.

### 11. Рост змейки

Если координаты новой головы совпали с координатами еды, хвост не удаляется. В массиве остаётся дополнительный элемент, поэтому змейка увеличивается на одну клетку.

Если еда не съедена, выполняется `snake.pop()` и длина остаётся прежней.

### 12. Счёт

Текущий счёт хранится в переменной `cnt`:

```js
let cnt = 0;
```

После поедания еды значение увеличивается и выводится на страницу через `textContent`:

```js
cnt = cnt + 1;
cntElement.textContent = cnt;
```

### 13. Рекорд

Максимальный результат сохраняется в локальном хранилище браузера:

```js
let record = Number(localStorage.getItem("snakeRecord")) || 0;
```

Если текущий счёт превысил рекорд, новое значение отображается на странице и сохраняется:

```js
if (cnt > record) {
  record = cnt;
  recordElement.textContent = record;
  localStorage.setItem("snakeRecord", record);
}
```

Благодаря `localStorage` рекорд сохраняется после обновления и повторного открытия страницы.

### 14. Запуск и повторная игра

До начала игры змейка неподвижна, а в центре Canvas показывается кнопка «Начать игру».

После нажатия:

- восстанавливается начальный массив змейки;
- устанавливается движение вправо;
- возвращаются начальные координаты еды;
- текущий счёт сбрасывается до нуля;
- скрываются сообщение и кнопка;
- запускается игровой цикл.

После проигрыша кнопка появляется снова. Перезагрузка страницы для повторной игры не требуется.

### 15. Сообщение об окончании игры

Изначально для сообщений использовался `alert()`, но такое окно требовало обязательного закрытия и блокировало страницу. Поэтому оно было заменено обычным DOM-элементом.

После проигрыша над кнопкой выводится одна из причин:

```text
Игра окончена: змейка столкнулась со стеной
```

или:

```text
Игра окончена: змейка столкнулась с собой
```

Сообщение не требует закрытия и скрывается при начале новой игры.

## Основные функции

| Функция | Назначение |
|---|---|
| `drawSnake()` | Рисует все части змейки с помощью цикла `for` |
| `drawFood()` | Рисует еду на Canvas |
| `clearCanvas()` | Очищает игровое поле перед новым кадром |
| `moveSnake()` | Вычисляет новую голову, перемещает змейку, обрабатывает еду и рост |
| `changeDirection(event)` | Обрабатывает нажатия клавиш со стрелками |
| `gameLoop()` | Выполняет один полный игровой шаг и запускает следующий |

## Основные переменные

| Переменная | Назначение |
|---|---|
| `canvas` | HTML-элемент игрового поля |
| `context` | Двумерный контекст рисования Canvas |
| `cellSize` | Размер клетки в пикселях |
| `snake` | Массив частей змейки |
| `food` | Координаты еды |
| `directionX`, `directionY` | Текущее направление движения |
| `directionChanged` | Запрет второго поворота за один шаг |
| `cnt` | Текущий счёт |
| `record` | Лучший сохранённый результат |

## Как запустить игру

Дополнительные библиотеки и установка зависимостей не требуются.

1. Открыть файл `index.html` в современном браузере.
2. Нажать кнопку «Начать игру».
3. Управлять змейкой клавишами со стрелками.
4. После проигрыша нажать «Начать игру» для повторного запуска.
