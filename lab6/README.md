# Лабораторная работа №6. ReactJS

## Цель работы

Получить навык разработки веб-приложений с помощью библиотеки ReactJS.

## Задачи

1. Изучить принципы работы с виртуальным DOM.
2. Изучить основы JSX.
3. Разработать два SPA: на классовых и функциональных React-компонентах.

Вариант №3 — новостной сайт.

## Что реализовано

Созданы два одинаковых по содержанию одностраничных сайта:

- `class-components` — сайт на классовых компонентах;
- `functional-components` — сайт на функциональных компонентах.

В каждом сайте имеются:

- два раздела — последние и популярные новости;
- переключение разделов с помощью состояния;
- вложенные компоненты `NewsList` и `NewsCard`;
- передача данных и обработчика через `props`;
- условный выбор заголовка и списка новостей;
- условный рендеринг сообщения для пустого списка;
- CSS на основе оформления предыдущей лабораторной, без Bootstrap и готовых компонентов.

### Соответствие заданию

| Требование методички | Реализация |
|---|---|
| Разработать два сайта | Отдельные директории `class-components` и `functional-components` |

| Использовать функциональные компоненты | Обычные функции, возвращающие JSX |
| Минимум две части сайта | Разделы последних и популярных новостей |

## Почему это два сайта, а не один

По заданию необходимо создать два сайта одной тематики разными способами. В работе они размещены в отдельных директориях и имеют разные исходные файлы:

```text
class-components/       — сайт №1 на классовых компонентах
functional-components/  — сайт №2 на функциональных компонентах
```

Первый сайт доступен по адресу:

```text
http://127.0.0.1:8000/class-components/
```

Второй сайт доступен по адресу:

```text
http://127.0.0.1:8000/functional-components/
```

Сайты намеренно одинаковы по содержанию и оформлению. Благодаря этому можно сравнить два способа реализации одного интерфейса: классы с `this.state` и функции с хуком `useState()`.

Корневой файл `index.html` не объединяет их в одно React-приложение. Это вспомогательная стартовая страница, содержащая две обычные HTML-ссылки:

```html
<a href="class-components/">Сайт на классовых компонентах</a>
<a href="functional-components/">Сайт на функциональных компонентах</a>
```

Тег `<a>` и атрибут `href` уже использовались в предыдущих лабораторных работах для переходов между HTML-страницами. Методичка ЛР6 не объясняет их повторно, поскольку они относятся к базовым средствам HTML. Стартовая страница добавлена только для удобного выбора одного из двух сайтов и не является отдельным требованием React.

## Две части внутри каждого сайта

Требование о двух частях относится отдельно к каждому из двух сайтов. В классовом и функциональном вариантах имеются разделы:

- «Последние новости»;
- «Популярные новости».

Для их переключения используются не ссылки `<a>`, а кнопки с обработчиком `onClick`:

```jsx
<button onClick={() => props.onChange("popular")}>
    Популярные новости
</button>
```

Обработчик изменяет переменную состояния `section`. React повторно формирует интерфейс и показывает нужный список, но не загружает новую HTML-страницу. URL в адресной строке при таком переключении не изменяется.

Таким образом, в работе выполняются два разных действия:

```text
Обычная ссылка <a> → выбор одного из двух самостоятельных сайтов
Кнопка React       → переключение части внутри выбранного SPA через state
```

## Классовые компоненты

Классовый компонент наследуется от `React.Component` и возвращает JSX из метода `render()`:

```jsx
class Header extends React.Component {
    render() {
        return <h1>Новостной портал</h1>;
    }
}
```

Состояние создаётся в конструкторе:

```jsx
this.state = { section: "latest" };
```

Изменять состояние напрямую нельзя. Для переключения используется `setState()`:

```jsx
this.setState({ section: section });
```

## Функциональные компоненты

Функциональный компонент является обычной функцией, возвращающей JSX:

```jsx
function Header() {
    return <h1>Новостной портал</h1>;
}
```

Состояние создаётся хуком `useState()`:

```jsx
const [section, setSection] = React.useState("latest");
```

`section` содержит текущее значение, а `setSection()` изменяет его и вызывает повторный рендеринг компонента.

## State и условный рендеринг

Переменная `section` принимает значения `latest` или `popular`. При нажатии кнопки состояние изменяется, React повторно вызывает рендеринг, но страница в браузере не перезагружается.

```jsx
const isLatest = section === "latest";
const displayedNews = isLatest ? news : news.filter(...);
```

Это условный выбор данных. Дополнительно используется условный рендеринг сообщения:

```jsx
{displayedNews.length === 0 && <p>В этом разделе пока нет новостей.</p>}
```

## Вложенные компоненты и props

Компоненты образуют следующую структуру:

```text
App
├── Header
├── Navigation
├── NewsList
│   └── NewsCard
└── Footer
```

`App` передаёт массив новостей компоненту `NewsList`:

```jsx
<NewsList title="Последние новости" items={displayedNews} />
```

`NewsList` перебирает массив и для каждого элемента создаёт вложенный `NewsCard`:

```jsx
{props.items.map(item => (
    <NewsCard key={item.id} item={item} />
))}
```

`props` позволяют родительскому компоненту передавать данные дочернему. Значения `props` внутри дочернего компонента изменять не следует.

## Краткое объяснение для защиты

> В работе созданы два одинаковых новостных SPA. Первый реализован классами, наследующими `React.Component`, и использует `this.state` и `this.setState()`. Второй реализован функциями и использует хук `useState()`. Компонент `App` хранит выбранный раздел. При нажатии кнопки состояние изменяется, React обновляет виртуальный DOM и перерисовывает только необходимую часть интерфейса. Данные передаются дочерним компонентам через `props`, а карточки новостей создаются вложенным компонентом `NewsCard`.

## Основные понятия

- JSX — HTML-подобный синтаксис внутри JavaScript.
- Компонент — самостоятельная часть интерфейса.
- Props — входные данные компонента, полученные от родителя.
- State — внутреннее состояние, изменение которого вызывает повторный рендеринг.
- Хук — функция React, добавляющая возможности функциональным компонентам.
- Виртуальный DOM — представление интерфейса в памяти, которое React сравнивает при обновлении.
- SPA — приложение, которое изменяет содержимое без полной перезагрузки страницы.
