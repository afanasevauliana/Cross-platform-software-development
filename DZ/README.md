# Домашняя работа «Разработка микросервисов»

Разработан простой новостной портал, продолжающий лабораторные работы №1–6.

## Что реализовано

- функциональное React-приложение;
- четыре раздела с переключением через `state`: главная, экономика, культура и добавление новости;
- регистрация, вход и выход пользователя;
- закрытие новостей от неавторизованных пользователей;
- формы на библиотеке Formik;
- AJAX-запросы через axios;
- Flask API, разделённый на `auth` и `news` Blueprint;
- хранение пользователей и новостей в MySQL из XAMPP;
- Apache из XAMPP для загрузки статических файлов и балансировки API между двумя экземплярами Flask.

Дополнительные необязательные возможности из методички — Docker, JWT, несколько экземпляров микросервиса и балансировка — не использованы.

## Подготовка MySQL в XAMPP

Запустить MySQL в панели XAMPP и создать пустую базу данных:

```sql
CREATE DATABASE news_portal;
```

По умолчанию используются стандартные параметры XAMPP:

```text
сервер: localhost
порт: 3306
база: news_portal
пользователь: root
пароль: отсутствует
```

Если пароль или другие параметры отличаются, перед запуском задать их через переменные окружения:

```powershell
$env:MYSQL_USER="root"
$env:MYSQL_PASSWORD="пароль"
$env:MYSQL_DATABASE="news_portal"
$env:SECRET_KEY="любая-случайная-строка"
```

Таблицы `users` и `news` создаются автоматически при первом запуске Flask.

## Установка и запуск

В PowerShell перейти в папку домашней работы и создать виртуальное окружение:

```powershell
cd D:\github\Cross-platform-software-development\DZ
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустить два экземпляра Flask в двух окнах PowerShell:

```powershell
$env:PORT=5001
.\.venv\Scripts\python.exe run.py
```

```powershell
$env:PORT=5002
.\.venv\Scripts\python.exe run.py
```

Запустить Apache в панели XAMPP и открыть сайт:

```text
http://localhost/Cross-platform-software-development/DZ/
```

Apache загружает статические файлы сайта и передаёт запросы `/api` балансировщику. Балансировщик по очереди направляет запросы экземплярам Flask на портах 5001 и 5002. Оба экземпляра работают с общей базой MySQL. React, Formik, axios и Babel подключаются через CDN, поэтому для загрузки библиотек нужен интернет.

## Порядок проверки

1. Открыть сайт — должна отображаться только форма входа.
2. Перейти к регистрации и создать пользователя.
3. Открыть раздел «Добавить новость».
4. Заполнить форму и добавить запись.
5. Перейти на главную и проверить строку в таблице «Новости пользователей».
6. Выйти из системы и убедиться, что таблица больше недоступна.
7. Войти с созданными логином и паролем.
