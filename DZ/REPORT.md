# Домашняя работа «Разработка микросервисов»

**Дисциплина:** Кроссплатформенная разработка программного обеспечения  
**Выполнила:** Афанасьева Ю. Р., группа ИУК4-43Б  
**Год:** 2026

## Цель работы

Получить навык разработки веб-приложений на основе микросервисов.

## Задачи

1. Разработать ReactJS-приложение.
2. Разработать микросервис для получения данных приложением с помощью Flask.
3. Реализовать регистрацию и авторизацию пользователей.
4. Организовать хранение данных в реляционной СУБД MySQL.

## Ход работы

Разработан новостной портал по варианту лабораторной работы №6. Клиентская часть состоит из функциональных React-компонентов. Компонент `App` хранит выбранный раздел в состоянии `section`. Пользователь может перейти между таблицей новостей и формой добавления без перезагрузки страницы.

Формы входа, регистрации и добавления новости созданы с помощью Formik. Проверяется заполнение обязательных полей. Для отправки AJAX-запросов применяется axios.

Серверная часть создана на Flask и разделена на два Blueprint:

- `auth_blueprint` обрабатывает регистрацию, вход, выход и проверку сессии;
- `news_blueprint` возвращает список новостей и добавляет новые записи.

Пользователи и новости хранятся в MySQL. Таблица `news` связана с таблицей `users` внешним ключом `author_id`. Пароли сохраняются в виде хеша. Доступ к API новостей разрешён только при наличии пользователя в сессии.

Apache из XAMPP загружает статические файлы React-приложения. Flask работает отдельно на порту 5000 и обрабатывает только запросы к API.

Полный исходный код находится в файлах `app/*.py`, `frontend/app.jsx`, `frontend/index.html` и `frontend/style.css`.

## Результаты работы

Создано веб-приложение, в котором пользователь может зарегистрироваться, войти в систему, просмотреть таблицу новостей, добавить новость и выйти. Неавторизованный пользователь не может получить список новостей или добавить запись.

## Вывод

В ходе работы были закреплены навыки создания интерфейса на React, работы с состоянием и компонентами, отправки AJAX-запросов, разработки Flask API и хранения связанных данных в MySQL.
